# Requisitos

Este documento detalha os requisitos do site a ser desenvolvido.

## Backlog do produto

*  não quer login no site.
*  Fazer um formulário e ter horário/data.
*  qual exames os animais fizeram no momento e os do passado.
*  uma página de cadastro e uma de listagem.
*  uma tela que lista todos os animais ou todos os donos e uma para cadastrar o animal.
*  não precisa de tela inicial.
*  barra de pesquisa.
